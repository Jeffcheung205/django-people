## Home Daily Program

A simple and interesting home daily Python program to help manage your daily tasks!

### Features
- 🌅 Personalized greetings based on time of day
- 💡 Daily motivational quotes
- 📝 Task management (add, view, complete tasks)
- ✨ Simple and easy to use

### Usage

Run the program:
```bash
python3 home_daily.py
```

The program will:
1. Greet you based on the current time
2. Show a daily motivational quote
3. Let you manage your daily tasks interactively

### Menu Options
1. **Add a task** - Add new tasks to your daily list
2. **Show tasks** - View all your tasks and their status
3. **Complete a task** - Mark tasks as done
4. **Show daily quote** - Get another motivational quote
5. **Exit** - Close the program

Enjoy your productive day! 🎉
